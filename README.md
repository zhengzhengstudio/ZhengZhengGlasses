# 铮铮眼镜 - 在线配镜定制平台

> 先确认合不合脸，再决定要不要配这一副。

## 一、项目概述

**铮铮眼镜** 是一个面向戴镜人士和眼镜商家的在线配镜定制平台。通过 AI 人脸分析技术，帮助用户在配镜前确认镜框是否适合自己的脸型，实现"所见即所得"的试戴体验。

### 项目动机

传统配镜流程存在以下痛点：
- 用户无法直观了解镜框上脸效果
- 瞳距、脸型参数需要线下测量
- 镜框选择依赖经验，缺乏数据支撑

**解决方案**：
- 利用 MediaPipe 进行本地人脸关键点识别
- 自动计算脸型参数和镜框适配度
- 实时试戴预览，直观感受效果

## 二、核心功能

### 1. 脸型参数采集
- **照片上传分析**：支持上传正脸照片进行 AI 分析
- **摄像头实时采集**：使用 MediaPipe 实时识别人脸关键点
- **多角度采集**：正脸、左转、右转、抬头、低头、张嘴、眨眼
- **参数估算**：脸宽、瞳距、鼻梁宽、镜圈宽度、移心量

### 2. 智能镜框推荐
- 根据脸型参数推荐合适镜框
- 考虑材质偏好（钛、板材、TR90）
- 考虑使用场景（屏幕、户外、阅读、运动）
- 计算适配评分和移心量

### 3. 实时试戴体验
- 摄像头实时叠加镜框预览
- 支持切换不同镜框样式
- 可调整镜框位置和大小

### 4. 配镜沟通
- 与商家或 AI 顾问沟通定制意向
- 发送采集数据和心愿单

### 5. 商家后台
- 维护镜框样板目录
- 查看顾客参数和定制意向
- 管理订单

## 三、目标用户

| 用户角色 | 需求场景 | 核心价值 |
|---------|---------|---------|
| **戴镜人士** | 在线挑选/定制镜框 | 试戴预览、参数采集、智能推荐 |
| **眼镜商家** | 在线接单、管理订单 | 接收顾客参数、维护镜框目录 |

## 四、技术架构

### 核心技术栈
- **前端**：原生 JavaScript + CSS
- **人脸分析**：MediaPipe Face Landmarker
- **服务端**：Node.js + Express
- **数据存储**：JSON 文件 → PostgreSQL（扩容后）

### 数据流
1. 用户上传照片或启动摄像头
2. MediaPipe 在浏览器本地识别人脸关键点
3. 计算脸型参数和推荐镜框
4. 数据缓存到本地存储
5. 服务器可用时同步到云端

## 五、项目亮点

### 1. 隐私保护优先
- 人脸照片默认只在本机处理
- 与商家沟通优先传参数，不传原始照片
- 提供删除照片和记录的入口

### 2. 渐进式体验
- 支持临时用户模式，无需登录即可体验
- 数据自动缓存，登录后同步

### 3. 离线可用
- MediaPipe 模型本地加载
- 所有计算在浏览器完成

## 八、使用流程

1. **开始录入** → 登录/创建临时用户
2. **采集数据** → 上传照片或摄像头采集多角度数据
3. **实时试戴** → 切换镜框，调整位置
4. **生成报告** → 查看适配评分和参数建议
5. **配镜沟通** → 把参数发给商家定制

## 九、启动方式

```bash
# 进入项目目录
cd website/api

# 启动眼镜站点服务器
node glasses_server.js

# 服务运行在 http://localhost:8114/
```
